# System-ESG V4.1 内容存取规则

## 可公开内容

- 300 个知识点目录、模块说明与公开来源元数据。
- 15 道已核准的免费样本题，以及完成作答后显示的答案依据。
- 公开考纲与历届高频考点重构的教学题；不得宣称为官方原题。

## 不作为正式或付费题库的内容

旧版 5,200 道自动生成题属于未审核研发草稿。V4.1 已从公开应用包移除，不能用于正式测验、认证、销售或人才评价。旧 Git 历史中的副本也不构成可发布题库。

## 受限制内容

未来 Pro、B2B、正式模考和认证题只存放于 `esg_question_bank_v41`。浏览器通过已认证会话和有效 entitlement 请求题干；答案与解析保存在独立 `answer_payload`，提交答案后由后端判分。前端不得打包、缓存或批量导出受限制答案。

## 发布条件

题目只有在 `verified=true`、`review_status=approved`，并具备来源、版本、生效日期和知识点映射后才能进入可用题池。题量不足时不得重复抽题或使用待审题补足。
