# Gate 3 真人試點前後測題組

本題組只使用 V4.1.5 已核准的中國法域題目。前測與後測使用同一組題目但重新排列題序及選項；主持人不得在前測後透露答案。每題 10 分，共 100 分。

## 題目 ID

1. `GT-CN-001`：基本準則在實施範圍另行規定前的適用方式。
2. `GT-CN-002`：氣候資訊使用者範圍。
3. `GT-CN-003`：氣候相關風險與機遇的重要性判斷。
4. `GT-CN-004`：範圍二排放的地點法披露。
5. `GT-CN-005`：上交所指南涵蓋的上市公司。
6. `GT-CN-006`：披露資訊品質要求。
7. `GT-CN-007`：指南附件的使用方式。
8. `GT-CN-008`：上交所 2026 版附件議題順序。
9. `GT-CN-009`：深交所 2026 年新增章節。
10. `GT-CN-010`：氣候披露綜合判斷（如版本資料中採用其他 ID，主持人須記錄實際 ID）。

## 執行方式

1. 在綜合法域或中國法域選定上述核准題。
2. 前測關閉即時解析，逐題記錄正誤。
3. 後測重新排列題目與選項；不得更改題意、答案或來源。
4. 匯出每位參與者的原始正誤紀錄，並將總分填入原始資料表。
5. 若第 10 題 ID 不存在，使用核准的中國法域綜合案例題，並在 `notes` 記錄替代題 ID。

## 答案治理

答案與解析以系統內核准題的 `correct_answer`、`answer_basis` 為唯一依據；本文件不另抄答案，避免本地副本與受版本控制的 Ground Truth 分叉。題目使用時必須同時顯示或保存 `source_id`、`source_authority`、`source_version` 與 `source_clause`。

## 測量限制

同題前後測可檢驗短期學習，但有題目記憶效應；Gate 3 報告必須如實揭露。下一輪內容擴充後應建立難度等值但題目不同的 A／B 平行卷。
