# System-ESG V4.1.5 Gate 2 修復與復驗報告

日期：2026-10-10
版本：V4.1.5 Gate 2 Revalidation
狀態：本地修復完成，未部署正式站，未進入 Gate 3

## P1 修復

### 1. 首頁主流程

- 首頁主要按鈕改為「開始練習」。
- 按鈕會清除舊篩選並直接進入目前法域的核准題練習；中國法域實測可取得 10 道核准題。
- 首頁不再把使用者導向題量不足而全部停用的 20／50／100 題模擬考試。

### 2. 能力功能名稱

- 學員端統一使用「能力追蹤」與「學習報告」。
- 移除「能力診斷／能力評估／能力證明／人才認證」等尚未具備正式流程的產品宣稱。
- 空白學習報告說明資料如何產生，並提供「開始練習」按鈕；有資料後按模組顯示作答量及正確率。

### 3. 練習篩選器

- 題型選項直接映射 V4.1 的 7 個 `question_type` 枚舉值：情境單選、情境複選、計算、找錯、決策排序、表單判讀及綜合案例。
- 題池只納入 `verified=true`、`review_status=approved` 且符合目前法域的題目。
- 來源選項由核准題的 `source_id` 動態建立，顯示來源機構及版本。
- 顯示符合條件／本次練習題數；無結果時顯示「清除篩選」。
- 瀏覽器回歸逐項操作模組、難度、題型及來源選項；有資料時核對每一題欄位，無資料時核對清除入口。

### 4. 題目可信度

- 移除固定「來源待審核」。
- 依 `review_status` 顯示已核准、審核中、草稿或已退回。
- 核准題顯示 `source_authority`、`source_version` 及 `source_clause`。

### 5. 個性化學習

- 預設開啟「僅顯示有核准題」，並依未作答／較低正確率排序推薦。
- 首層只顯示模組摘要；使用者展開後才看到該模組的知識點。
- 每頁最多 3 個模組，提供上一頁／下一頁，不再把全部知識點放在同一層。

### 6. 固定解析名稱

- 「AI 教練」改為「分步解題教練／分步解題引導」。
- 「提交給 AI 教練」改為「提交答案」。

### 7. 基本可存取性

- 首頁模組卡及學習知識卡改為原生 `button`。
- 主要操作可使用 Tab、Enter、Space；加入清楚的鍵盤焦點樣式。
- 搜尋框、下拉選單及動態作答輸入加入可辨識名稱。
- 桌面與手機導航以 `aria-current="page"` 標示目前位置。

## P2 改善

- 試用版知識頁新增「下一知識點」與「練習相關題目」。
- 零錯題時停用「只刷錯題」，並提供「開始普通練習」。
- 第一次登入不再誤顯示帳號切換提示；只有登入中的帳號確實改變時才提示。
- 390px 手機頂部只保留同步狀態及退出操作；隱私與管理入口收進既有手機導覽。
- 手機與桌面統一使用學習報告、錯題回補等產品用語。
